# Spike: share images with the Images binding

Ticket: "Share images with the Images binding: spike" (wayfinder map "Build the Berghald site and the Vefstjórn MVP").
Run 2026-11-19 on a throwaway Worker `berghald-spike-share` (workers.dev) and R2 bucket `berghald-spike-share-tmp`, both deleted afterwards. Test photos are synthetic (generated by `gen-assets.mjs` and `tools/covers.mjs`), never client photos. `public/` is gitignored; regenerate it with those scripts.

## Verdict

**It works on Workers Free, with one condition: the cover passed to the binding must be a small derivative (≈ 1200 px wide, ≤ ~300 KB), never the original upload.** The browser-Canvas fallback is not needed.

- `.text()` with Outfit (WOFF2 from the Worker's own static assets) renders cleanly: kerning and ligatures applied, all Icelandic letters correct.
- Worker CPU is driven by **how many bytes go into the binding**, not by the drawing. The input stream is copied through the isolate at roughly 6–10 ms per MB. Text and overlay layers add ~0–3 ms.
- `wrangler dev` (local) does **not** support it: `.text()` fails, and `.draw()` overlays are silently dropped.

## Text rendering

- **Size unit:** `size` is in pt but renders as ~1 px per pt (`HHHHHHHHHH` at 60 → 431 px wide vs 438 px from advance widths; cap height 43 px vs Outfit's 0.70 em). Calibration factor 1.0 works.
- **Fonts:** WOFF2 served from the Worker's own static assets (`/fonts/outfit-700.woff2`, the 14 KB fontsource `latin` subset) loads fine. The `latin` subset covers þ ð æ ö á é í ó ú ý Þ Ð Æ Ö Á É Í Ó Ú Ý, „ “ and –; all rendered correctly.
- **Shaping:** kerning and the `tt` ligature are applied by the renderer. Our line-break width table (advances only, no kerning) slightly overestimates width, which is the safe direction.
- **Placement quirk:** a text layer is positioned by its **ink box**, not its baseline or font box. `bottom: N` puts the lowest ink pixel at N, so a line with descenders (g, j, y, „) sits higher than one without, and line spacing looks uneven. Same on the left: the left side bearing is trimmed. **Fix (verified):** store each glyph's `yMin` and `xMin` alongside its advance; for each line set `bottom = baselineFromBottom − maxDescent(line)` and `left = PAD + lsb(firstGlyph)`. With that, baselines line up exactly.
- **Line wrapping:** greedy word wrap against a precomputed Outfit 700 table (`src/outfit-700-widths.json`, 2 KB: `[advance, xMin, yMin, yMax]` per char, Latin-1 + Icelandic punctuation) at max width 1056 px. Long titles wrap to 3 lines at 72 pt and the last line is ellipsised. Output looked right in every case tried (2- and 3-line titles, all-caps, all Icelandic letters). A single-letter word can end a line (e.g. "… sumarhús í / Þingvallasveit"); optionally keep short words with the next one.

## Local development

`wrangler dev` (wrangler 4.163.0, local mode):

- `env.IMAGES.text(...).output()` → `IMAGES_TRANSFORM_ERROR 9523: expected image in request, got null`.
- `input(...).transform(...).draw(...)` returns the resized cover with **all draw layers silently dropped** (no gradient, no text).

So local dev and Playwright can't verify the image. Generation must be fire-and-forget with the static default as fallback, and tests should assert the R2 key/`og:image` URL, not the pixels.

## Build rules that follow

1. **Feed the binding a derivative, not the original.** Use the cover's ~1200w JPEG/WebP derivative (≤ ~300 KB) as input. With a 6.5 MB phone original, CPU is 65 ms p50.
2. **Draw is cheap; keep the layout in layers:** cover → static gradient PNG → one `.text()` per line → kicker.
3. **Store, don't respond.** Write to R2 at the versioned key on publish (`ctx.waitUntil`), serve as an immutable file. Wall time is ~0.3 s; that's fine in `waitUntil`.
4. **Position text by ink box**, correcting with the glyph table's `yMin`/`xMin` (above).
5. **Font from own static assets** (WOFF2, `latin` subset is enough for Icelandic).
6. **Fallback stays:** static default share image when generation fails or in local dev.
7. **Quota:** each unique source + parameters counts as one transformation (5,000/month, shared with photo widths). This spike used at most ~300 of this month's allowance.

## Consequence for the media pipeline (separate ticket)

The same input-bytes cost applies to every Images binding call, including a Worker `/img/<w>/<key>` route and blurred previews made at upload. Passing a multi-MB original through the binding in a Worker request costs ~6–10 ms CPU per MB. Check this in the media upload spike.

## Files

- `src/index.ts`: the spike Worker (`/measure`, `/info`, `/cover`, `/og`, with `src=r2`, `cover=`, `store=1`, `align=0`).
- `src/outfit-700-widths.json`: glyph table, generated by `gen-assets.mjs` (also makes the gradient PNG and a synthetic cover).
- `tools/`: synthetic covers, render and load scripts, `stats.mjs` (percentiles from `wrangler tail --format json`).
