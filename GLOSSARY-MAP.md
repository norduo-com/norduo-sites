# Glossary Map

## Contexts

- [Vefstjórn](./packages/cms/GLOSSARY.md): the shared CMS; generic content terms that every site's config is built from
- [Berghald](./sites/berghald/GLOSSARY.md): Berghald's business terms (projects, services, seasons)

## Relationships

- **Berghald → Vefstjórn**: Berghald's terms are expressed as Vefstjórn collections, singletons and fields in `sites/berghald/cms.config.ts`. Vefstjórn never names a Berghald term.
